# SS ENGINE

SS ENGINE is an AI-powered creative development platform.

## Features
- AI Chat
- Multiple AI Providers
- Coding AI
- Research AI
- Creator AI
- Backup AI

## Installation
npm install

## Start Backend
npm start

## API Routes
GET /
GET /api/status
POST /api/chat

## API Configuration
Use environment variables to configure AI providers.

Never publish real API keys on GitHub.
